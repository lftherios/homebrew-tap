# homebrew-tap

Homebrew formulae for [session.link](https://session.link).

```sh
brew install lftherios/tap/slink
```

The formula is updated from [lftherios/session-link](https://github.com/lftherios/session-link) on each release:
`node scripts/update-formula.mjs <version> SHA256SUMS.txt` there, then copy `packaging/homebrew-tap/Formula/slink.rb` here.
